Bagaimana Halaman Ini Bekerja

Tiga unsur multimedia di halaman ini dibuat dengan cara yang berbeda-beda:

1

Gambar, dari Kode SVG 🖼️

Ayamnya tidak memakai foto atau gambar unduhan. Badannya digambar dengan kode SVG dan sengaja dipecah jadi potongan terpisah: badan, sayap, ekor, leher-kepala lengkap dengan jengger, pial, paruh atas dan paruh bawah, lalu dua kaki. Potongan terpisah ini yang membuat langkah berikutnya, animasi per bagian, jadi mungkin. Pemandangannya juga digambar dengan kode: langit pagi, matahari, awan, pagar kandang, dan tanah tempat jagung berserakan.

2

Suara, Rekaman Ayam Asli 🔊

Kokok dan koteknya adalah rekaman ayam betulan, bukan suara buatan. File kokok.mp3 dan kotek.mp3 diambil dari Wikimedia Commons (domain publik, direkam oleh alys via PDSounds), dipotong dari rekaman yang lebih panjang lalu volumenya dinormalkan supaya pas sekali klik. Di halaman ini rekaman diputar memakai HTML5 Audio dan keluarannya dilewatkan ke AnalyserNode dari Web Audio API, makanya batang equalizer kecil di pojok kiri panggung dan denyut matahari bergerak mengikuti keras-lemahnya suara rekamannya.

3

Gerak, Walk Cycle CSS + JavaScript 🏃

Jalannya memakai teknik walk cycle: kedua kaki diayun bergantian dari poros pangkalnya, badan ikut naik-turun, kepala maju-mundur khas ayam, sementara pagar dan tanah digeser dengan kecepatan berbeda untuk efek parallax sehingga ayam terasa benar-benar berpindah tempat. JavaScript mengatur pergantian perilakunya: berjalan, berhenti mematuk (skor bijinya bertambah dan tercatat di panel aktivitas), lalu mendongak berkokok dengan sayap mengepak dan paruh membuka.

🎬 Versi Videonya, Dirender Pakai Python

Adegan yang sama dirender ulang menjadi video MP4 oleh program Python terpisah. Setiap frame digambar satu-satu dengan Pillow (total 240 frame), lalu FFmpeg menggabungkan gambar dan suara menjadi satu file video berdurasi 10 detik: berjalan, mematuk sambil berkotek, lalu berkokok. Suara di videonya memakai rekaman ayam asli yang sama dengan di halaman web ini.

pip install pillow numpy
python buat_ayam_bergerak.py
